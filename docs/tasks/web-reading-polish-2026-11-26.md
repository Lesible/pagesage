# 网络书组织、大纲、双语阅读与选择控件

日期：2026-11-26。状态：实现、自动验证与 Linux 安装核对完成。

## 用户目标与本轮范围

- 同一网站的多个网页归入一个来源目录，每个网页仍保留独立快照和定位；
  不凭域名推断两份正文相同，也不自动合并文章。
- 网页、EPUB/Markdown 与 PDF 的目录统一标题层级，移除每行重复百分比、
  文件路径及叶节点的大图标；PDF 内置目录页码置于行尾，支持折叠父节点。
  桌面与移动共用标题树行，选中位置仍按原文偏移或 PDF 页内位置计算。
- AI 配置/范围及翻译设置复用共享下拉控件；同一组件提供表单与紧凑形态，
  菜单、焦点、禁用项、选中状态和尺寸约束统一维护。
- 阅读器提供可发现的原文/译文对照入口，接入已有翻译配置，
  译文持久保存并按来源、文本与翻译配置隔离；原文定位与批注不使用译文偏移。
- 网页按段落对照，PDF 按当前页对照。原文和代码等不可翻译结构保留；
  翻译失败/取消不能缓存为空成功，切章/翻页后的旧请求不能覆盖新来源。

## 实际实现与边界

- 网络书按 URL authority（域名与显式端口）生成来源分组，保持首次出现的来源顺序
  和组内网页顺序；每个网页仍独立保存与跳转。同一 URL 的不同 fragment 沿用既有去重；
  不凭同站点推断两篇文章相同，也不抓取整个站点导航冒充本页大纲。
- `ReaderDocumentOutline` 复用至网页、EPUB、Markdown 单文件/目录文件；
  `ReaderPdfOutline` 根据已有 level 构建折叠关系，二者共用 `ReaderOutlineRow`。
  过滤保留命中标题的父级；同一文件中多个标题也只有一个当前项。
- `AppSelectField` 提供表单与紧凑形态，AI 配置、上下文范围、翻译服务、
  语言和阅读方式共享菜单尺寸、键盘焦点、禁用项与主题。短屏键盘场景的标题行可压缩。
- 网页/PDF 的桌面工具条增加「对照翻译」，移动端位于「更多」。
  入口先读本地译文，再用「翻译当前网页」或「翻译本页」补缺失内容。
  设置按钮直接进入独立翻译菜单；阅读方式包含仅原文、原译对照、仅译文。
  开启对照时收起 PDF 浮动操作栏，避免遮挡对照配置；缩放、跳页与识别仍可从顶部「更多」进入。
- 网页在原生 block 流中逐段配对，宽屏左右、窄屏上下；原文继续负责划线与定位，
  译文使用隔离选区。代码块、公式、表格和图片保持原文一次；内联代码、公式与 URL
  不发送，按原值拼回译文。EPUB/Markdown 本轮改目录，不包含双语渲染接入。
- PDF 保留原生 Canvas，当前页译文独立滚动；窄屏上下分区。页级文本抽取在 isolate，
  不调用整本文本遍历；单通道抽取并跳过快速翻页中已过期的排队页，避免并发解析大 PDF。
  无文本时只接受同来源、有效签名的既有 OCR，否则提示先识别。
  不重建 PDF 版式，也不伪造几何框的精确段落定位。
- schema 13 → 14 新增 `reading_translations`，以书籍/来源/单元/输出指纹唯一，
  每个完成的请求片段立即保存；同一长段后续片段失败时保留已付费结果。
  来源包含网页 snapshot/textRevision，或 PDF 文件、页号、抽取/OCR 版本及文本 hash。
  输出指纹包含供应商/协议/endpoint/语言/模型/AI 输出参数/规则版本，不含密钥及配置显示名。
  改服务输出、来源或语言不误命中；重开/断网/删除服务后仍可查看已保存版本。
- 取消、关闭、翻页、换配置使旧请求失效；正在保存的结果只能归属冻结来源。
  保存失败保留会话内结果，重试优先落盘；切换来源再返回也保留尚未保存片段。
  数据库备份自动包含译文，恢复检查新表，删书按外键级联。
- 恢复时同步重映射翻译配置引用的 AI profile ID，清空翻译凭据绑定与待清理引用，
  避免断开的 AI 配置和在目标设备误用已有安全存储密钥；已保存译文与输出身份保留。

自动可见段预取、跨快照文本复用、强制重译的历史版本管理、术语表、
独立后台翻译作业与 PDF 几何级互相定位不在本轮交付中。
PDF 对照要求原 PDF 仍可访问；当前数据库备份含译文，不额外打包原 PDF 文件。
