### W0：先证明能抽取和离线呈现

- 复核现有 HTML、网络、hash、图片与 isolate 依赖，先复用已有能力。
- 比较 Dart 可用抽取方案与 Readability 类方法，确认代码块、表格、中文和图片的损失。
- 冻结安全清理、资源预算和编码输入；用同一正文解析器计算实际 textRevision。
- 产出候选选择记录，说明 Linux/Windows/Android 的编译支持与未实测边界。
- 退出条件：有可复现样本和质量分项；不支持场景可诊断，运行时/许可证成本可接受。
  达不到目标先调整方案，不让选择风险拖到功能完成后。

### W1：建立真实契约

- 对 `BookFormat`、`ReadingLocatorType` 及全部 switch/映射做消费者清单。
- 按实施时最新版本安排迁移，不预占版本号，不清库。
- 受管网页书籍与外部 Markdown 目录路径明确分流。
- 章节、来源、快照、操作身份不使用 URL/hash/排序号代替 UUID。
- 退出条件：迁移和 locator 往返通过；既有三格式行为保持，创建空合集可持久化。

### W2：第一条可用链路

- 本地候选发布与正文/图片持久化一并实现，不能先交付“只能在线读”的壳。
- 复用原生渲染模型；只装载当前网页，章节与大纲分开。
- 接入页内锚点、位置保存、重开恢复、主题与缺失资源提示。
- 退出条件：断网、删除临时缓存并重新启动服务对象后仍能读已保存章节；
  不发生外部资源请求，不加载整书正文。

### W3：把更新和中断做完整

- 逐章阶段检查点、短事务 CAS、epoch、tombstone 与任务中心一起接入。
- 处理 304、本地损坏、没有变化的 200、图片补齐和失败保留旧版。
- 整本刷新冻结清单、限制并发、混合结果统计、重试和取消。
- 阅读中的快照固定；用户应用新版时才做可靠位置转换。
- 退出条件：发布各阶段失败/重启、重复操作和删除竞态可复现验证。

### W4：让阅读资料和来源保持一致

- 新 locator 贯通进度、批注/书签、笔记、搜索、AI 上下文与导出。
- 刷新后只做可靠重锚；原摘录和旧引用保留。
- 将网页显式加入 indexer 和 AI 装载器，不落入 EPUB 默认分支。
- 退出条件：真实 SQLite 上刷新、重建、检索与引用跳转一致；错误重锚不画高亮。

### W5：让本地数据可恢复

- 备份协议与文件保留集一起升级，继续读取 v1。
- 真实新根目录恢复验证正文、资源、阅读资料与索引。
- 刷新/备份/GC 共享 pin 与协调边界；恢复包含持久日志和失败回滚。
- 同步隐私和用户说明，准确区分旧备份与新备份包含内容。
- 退出条件：恢复后断网可读；并发备份不会引用缺失对象；清缓存不删除书库内容。

### W6：联合交付

- 按[验证矩阵](02-validation.md)回归，不只证明新增回调或接口被调用。
- 检查真实样本图文、长文与大量章节的性能，以及亮暗/大字号/窄屏离屏截图。
- 完成静态分析、相关回归与静默 Linux 构建安装核对。
- 记录真实窗口、其他平台和站点兼容边界，不把未测试项写成完成。
- 退出条件：R1–R9 无未说明的功能缺口；阻断缺陷关闭，有据可查。

## 3. 开工前仍需用实验收敛的选择

这些是实施中的技术决策，不要求用户重复确认已同意的需求：

| 决策 | 本次默认方案 | 如何收敛 |
| --- | --- | --- |
| 正文抽取器 | 语义区域优先 + reader_mode HTML adapter 回退 | W0 原型选定；应用接入前复核许可和隔离预算 |
| 图片与复杂内容 | 支持格式本地保存，不支持内容明确回退 | W0 图文样本与安全评估 |
| schema / 表字段 | 以真实 v12 为当前基线，新增章节/快照/操作 | W1 复核当时最新结构与迁移 |
| 相同 URL 去重 | 同合集定位已有章节，提供刷新 | W1/W3 规范化与交互测试 |
| 快照保留 | 当前版及用户资料/会话/备份引用必须保留 | W5 测试清理与占用上限 |
| 预算与并发 | 使用架构文档的保守初值 | W0/W3 性能测量后固化 |

首个实施目标是 W0 的“同一网页从抽取到本地原生呈现”的最小实验，
之后进入 W1/W2。不是先做一排网页按钮，也不是直接把所有网页拼成 EPUB。

使用隔离工具包 `tool/web_capture_eval`，不把未选定的抽取依赖接入应用产物，
不读写用户书库。比较 reader_mode 原始输出、面向语义文章结构的候选策略，
并对接当前 `EpubChapterParser` 验证实际原生文档边界。

精确入口计划为 `tool/web_capture_eval/test/article_extractor_test.dart`、
`native_article_test.dart`、`evaluation_test.dart`；冻结夹具不少于 20 项，
真实网页对照不少于 10 项。安全清理验证应证明不可信脚本、外部资源地址和事件属性
不会进入可执行或自动联网路径；资源对象及图片持久化在 W2 验证，不以抽取测试代替。
证据放入 `.local-data/validation/web-collections-2026-11-26/`，
不把下载的真实网页或截图提交到公开仓库。
