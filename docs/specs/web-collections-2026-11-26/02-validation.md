# 网页合集：验证与验收计划

日期：2026-11-26。本文件保留完整验收计划；
实际已运行测试及未覆盖场景见[首版验证记录](07-implementation.md)。
下文计划场景不能直接视为已通过记录。

## 1. 验证分层

| 层次 | 证明什么 | 不代替什么 |
| --- | --- | --- |
| 冻结 HTML/资源夹具 | 抽取、规范化、资源解析和错误分支可复现 | 真实站点可访问性 |
| 本地 HTTP 测试服务 | 重定向、超时、304、流式大小、资源补齐和取消 | 外网站点全部变体 |
| 临时文件 + 真实 SQLite | 迁移、快照发布、重启恢复、索引、备份回滚 | 完整阅读窗口 |
| widget / 离屏截图 | 菜单、状态、页签、大纲、主题、键盘与溢出 | 实际 OS 生命周期 |
| 真实公开样本抽查 | 正文和图文抽取效果、兼容边界 | 未覆盖网站或登录页 |
| 真实设备/窗口 | 系统网络、生命周期与实际阅读交互 | 其他未运行的平台 |

默认静默执行；不启动新终端、可见应用或桌面 integration_test。
真实窗口与设备条件不具备时明确记为未验证。

## 2. W0 抽取评测

### 2.1 冻结样本

先建立不少于 20 个自建/可再分发 HTML 夹具，覆盖：

1. 中文、英文、混合文本与 emoji/组合字符。
2. 常见非 UTF-8 编码、无 charset、错误 charset 的诊断。
3. 多级标题、列表、引用、脚注/页内锚点、重复标题。
4. 代码块、内联代码、表格、公式和图片替代文本。
5. 相对地址、带 query 图片、懒加载、`srcset`、重复资源。
6. 缺闭合标签、错误嵌套、`base` 标签与空正文。
7. 有大量导航/广告的文章与正文很短但有效的页面。
8. 登录墙、挑战页、仅 JavaScript 框架壳。
9. 外链 CSS、脚本/事件属性、iframe、危险链接。
10. 不支持的媒体、畸形图片、图片解码像素超限。

真实网页至少抽查 10 篇，覆盖中文文章、英文文章、技术文档、图文教程及含表格/代码页面。
记录取样时间、来源、必要的截图/人工对照和允许保留的本地样本。
不能把网上文章整站镜像进公开仓库；自动回归以自建夹具为主。

### 2.2 比较与初始门槛

候选使用同一输入，分别记录正文保留率、杂质比例、标题层级、图片可用率、结构损失、
单页耗时、峰值内存、平台依赖及许可证；人工标注正文作为对照。
不能仅以“抽出一段文字”判优，也不能以另一个抽取器的输出当唯一真值。

初始准入目标（待 W0 实测后固化，不是现有能力声明）：

- 支持范围内的文章，人工标注正文字符保留率不低于 95%，非正文字符混入不高于 5%。
  预先定义空白与 Unicode 规范化的评测口径，它不改变运行时定位坐标。
- 必要代码、表格、标题与图片逐项检查；总体字符分数不能掩盖关键结构丢失。
- 登录/挑战/框架壳夹具不得误报为完整成功；危险执行内容不得进入可执行路径。
- 不支持格式必须给诊断；合法短文不得只因字符数阈值被拒绝。
- 准确率和耗时逐类报告，不把 10 篇样本得分宣称为通用网站支持率。

若 Dart 候选达不到门槛，先记录失败类别并决定补规则/更换方案，
再决定是否增加运行时；不带着未验证的复杂依赖进入完整功能开发。

## 3. 功能与失败矩阵

| ID | 场景 | 必须观察到的结果 |
| --- | --- | --- |
| V01 | 建空合集、重启、加首章 | 书库可管理；状态明确；稳定 ID 不变 |
| V02 | 多章切换与标题大纲 | 仅装载目标网页；页签不自动切换；高亮唯一 |
| V03 | 正文+图片保存后断网重启 | 不访问网络即可读；本地资源解析成功 |
| V04 | 部分图片失败/超限 | 正文可读；缺失计数准确；能重试 |
| V05 | 单章 200/304/内容未变 | 更新时间与检查时间区分；无无意义新版本 |
| V06 | 304 但本地正文/图片丢失 | 检测损坏或不完整，完整获取/资源修复；不能假报完整 |
| V07 | 刷新断网/超时/404/登录墙 | current 指针与旧正文保持；可重试 |
| V08 | 写入/flush/rename/数据库提交失败 | 旧版本仍可读；无部分发布或资源覆盖 |
| V09 | 在发布各阶段模拟进程中断 | 重新打开数据库/存储并跑恢复；以已提交指针为准 |
| V10 | 重复刷新、取消后迟到结果 | 同章不并行覆盖；旧 epoch 不发布 |
| V11 | 获取中删章/删书、排序/改名 | 删除不复活；用户元数据不被网络结果覆盖 |
| V12 | 整书刷新混合成功/失败/取消 | 按冻结清单统计；可只重试失败项 |
| V13 | 阅读中发布新版、存在选区/草稿 | 当前快照稳定；采用新版不突然跳首、不丢草稿 |
| V14 | 修改正文后批注重定位 | 唯一锚点才画高亮；重复/缺失锚点明确降级 |
| V15 | 图片补齐但正文不变 | snapshot/sourceRevision 更新；textRevision 和正文位置稳定 |
| V16 | 来源变化时索引/查询/删章竞态 | 旧文本不冒充当前；索引旧任务不可恢复删除内容 |
| V17 | 搜索命中与 AI 引用跳转 | 网页/版本/区间匹配；能说明当前或历史来源 |
| V18 | 新旧 locator 往返与损坏输入 | 旧三格式不变；网页显式解码；不误走 EPUB |
| V19 | v12 真实结构迁移与旧备份 | 书籍、笔记、密钥引用、OCR 任务等既有数据不丢 |
| V20 | v2 备份后换根目录、断网恢复 | current 和引用历史、图片、批注及搜索链路可用 |
| V21 | 备份与刷新/GC 同时运行 | 归档中数据库引用的文件齐全、校验一致 |
| V22 | 恢复校验/切换阶段失败或中断 | 原数据库及资源可恢复，不留下半新半旧 |
| V23 | 归档路径穿越/符号链接/超预算 | 在切换前拒绝，原库不受影响 |
| V24 | 清缓存、GC、删章/删书 | 活动/被引用/pin 快照不误删；无引用对象可回收 |
| V25 | signed query、重定向、跨源资源 | 地址不误合并；脱敏日志不泄漏 token 或正文 |
| V26 | 亮/暗、窄屏、大字号、键盘 | 正文优先、操作可达、有语义标签，无溢出 |

V09/V22 至少包含写文件后提交前、数据库提交后通知前，以及资源切换与恢复日志
更新之间的中断。仅抛异常后继续使用同一内存对象不算重启恢复测试。
断网测试用拒绝所有请求的真实网络 adapter/本地服务证明“没有请求”，不只切一个 UI 状态。

## 4. 规模与性能

在记录 CPU、内存、系统和构建模式的同一 Linux 环境执行：

- 合集元数据规模 1、100、1000 章；打开一章时断言只解析该章，
  切章缓存设定上限，不随总章数保留全书正文/图片。
- 章长覆盖普通文章与长文，记录首屏时间、切章时间、滚动帧、进程 RSS、
  单页抽取峰值与资源解码峰值；不能只测 Dart heap。
- 整书刷新 1000 章使用本地 HTTP 服务，混入失败、慢响应和重复操作，
  核对并发/队列上限、取消延迟、统计、重启恢复和内存释放。
- 持续阅读期间后台刷新和索引，不允许主 isolate 进行长时间同步解析/压缩。
  通过时间线判断卡顿来源，不凭单个耗时推断 UI 流畅。

初始目标：已保存普通章节（约 3 万 UTF-16 单位、15 张受控图片）本地首屏 p95
不高于 500 ms；1000 章与 100 章同一网页打开耗时差异不超过 20%。
图片解码、首屏和文件 I/O 分项记录，冷/热样本分开，每组至少 30 次；
相对差异需同时报告绝对毫秒，过短样本不以百分比单独判失败。
以上是待测目标，W0/W2 结合实际设备建立基线；未测时不写“性能已达标”。

## 5. 计划测试归属与执行方式

测试拟放入现有分层下（实施时确定最终路径，不提前创建空测试）：

| 测试族 | 覆盖 |
| --- | --- |
| `web_article_extractor_test.dart` | 冻结抽取、规范化、结构和安全转换 |
| `web_capture_service_test.dart` | HTTP、图片、预算、取消与错误保留 |
| `web_snapshot_store_test.dart` | 不可变对象、校验、文件失败及 GC |
| `web_chapter_repository_test.dart` | 真实 SQLite、CAS、删章与重启恢复 |
| 网页 schema migration tests | v12/实施前版本到新版、保留既有数据 |
| `web_book_session_test.dart` | 独立装载、排序、位置转换与固定快照 |
| 网页阅读/管理 widget tests | 章节/大纲、状态、菜单和用户编辑 |
| 网页搜索/AI provenance tests | 版本一致性、区间、高亮和历史来源 |
| 扩展已有 export/restore tests | v1/v2、换根目录、pin、失败回滚 |

每阶段先运行命名的受影响测试和 `flutter analyze`，最终按交付范围执行联合回归；
不以某次旧版本全仓数字代替新变更验证。涉及 Dart 的变更只格式化改动文件。

未来产生应用变更后，静默执行 Linux 构建/安装：

```bash
CMAKE_BUILD_PARALLEL_LEVEL=4 bash tool/install_linux.sh
```

安装后核对 bundle 与安装目录；不自行新开应用窗口或终止用户进程。
Windows/Android 的编译、安装、设备阅读与后台恢复分开记录，未运行不宣称通过。
本轮仅写文档，不需要构建、安装或重复跑 Flutter 测试。

## 6. 证据与联合验收

通过文档记录命令、退出码、样本版本和结果；正文、完整 URL 参数、密钥、网页截图

5. 实际窗口和其他平台的已测/未测边界。

不能用“任务回调触发”“生成了 ZIP”“存在本地 HTML 文件”代替实际阅读、
内容完整性、定位和恢复验证。
