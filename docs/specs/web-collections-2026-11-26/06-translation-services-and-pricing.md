# 翻译服务免费政策、价格与接入选择

核对日期：2026-11-26。状态：官方资料调研，不代表已实现 adapter、
已使用用户凭据实测，或当前账号必定享有公开免费额度。
配套行为设计见[双语阅读与持久译文](05-bilingual-translation.md)。

## 1. 沉浸式翻译可借鉴什么

官方 PDF 资料提供基础/高级翻译、双语对照、识别与导出路径；
FAQ、更新日志与插件资料也说明存在本地译文缓存、清缓存和缓存未命中的情况。
因此可借鉴分段翻译、多引擎与双语阅读体验，不能推断其所有 PDF 译文都永久落盘、
永不重复请求，或付费插件订阅包含可供 PageSage 调用的任意厂商 API 额度。

PageSage 的目标是「原文来源 → 页/段单元 → 翻译 → 本地持久保存 → 反复离线阅读」。
PDF 优先按需抽取文字；扫描页复用本地 OCR，仅把本页需要翻译的文本发给所选服务。
左右对应以页号、原文单元与几何关联实现，不先购买厂商整份 PDF 翻译能力。
无需将原始整本 PDF 发到翻译服务，也不引入浏览器扩展运行时。

## 2. 计费口径先分清

- 传统机器翻译通常按输入字符计费；空格、标点和标签等是否计数按服务定义，
  不能统一当成「汉字数」。
- 翻译大模型通常分别计算输入与输出 token。英文 token、中文字符、PDF 页数
  不能用 1:1 换算；上下文、术语说明和提示词也可能进入输入用量。
- 按页翻译不等于购买厂商「文档翻译」API。本文表价是文本翻译，
  原文抽取、本地 OCR、PDF 布局由本应用承担。
- 免费网页版、沉浸式翻译订阅、API 免费额度和新用户体验金是不同产品。
  选服务需开通对应 API；最终资格、税费、币种和区域由该账号的控制台决定。

## 4. 成本示例与选择建议

只作同口径演示，不预估用户书籍页数或真实字数：

- 已超免费量的 100 万输入字符：百度高级版公开起始价 ¥49；
  有道普通文本起价 ¥48；Google NMT 为 $20。
- 一次任务总计 100 万输入 token + 100 万输出 token：
  Hy-MT3 为 ¥2.50，Hy-MT3 Pro 为 ¥10，
  Qwen-MT Flash 为 ¥2.65，Qwen-MT Plus 为 ¥7.20。
- 上述 token 示例不等于「翻译 100 万汉字」，也不含未知网络失败重试、
  额外上下文或服务商税费；不同服务的 token 计量也可能不同。
- 相同来源/上下文和输出设置已经持久保存时，再次打开应为 0 次翻译网络调用；
  重新翻译、模型/语言改变或来源内容改变才处理相应缺失单元。
  本地不能保证「服务已计费但网络没返回」时的恰好一次收费。

建议先接已有 AI 配置引用和 Qwen-MT Flash，跑通网页/PDF 的保存与对照；
用 Hy-MT3 做成本和质量对照，支持有账号用户选择 DeepL。
百度适合希望使用对应免费月额度且接受认证/限频的用户；
Google/有道按网络、语言、账号条件提供后续适配。
没有使用同一组真实样本评测前，不作「便宜就同样好」或「一定优于 DeepL」的结论。

设置按翻译服务独立配置默认目标语言、术语表与风格；密钥进安全存储。
内置价目最多用于带日期估算，不显示无法查询的「精确剩余额度」；
服务切换只影响新请求，不能把已经保存的译文自动刷新成新的一笔费用。
